## Technology Stack

```
Frontend:    React 18 + Vite + Tailwind CSS + Plotly.js
             │
Backend:     Django REST Framework + Django CORS
             │
Database:    SQLite (Development) / PostgreSQL (Production)
             │
ML Library:  Python + scikit-learn + XGBoost + SHAP
             │
Deployment:  Heroku/AWS (Backend) + Vercel/Netlify (Frontend)
```

```

      │              │               │             │           │
      ▼              ▼               ▼             ▼           ▼
   Browser       Django CORS    Django Auth   Input Validation  JSON Response

This architecture provides:
- ✅ Scalable frontend with React
- ✅ Robust backend with Django REST API
- ✅ Powerful ML library with ChronoCast
- ✅ Secure data handling and validation
- ✅ Production-ready deployment setup
- ✅ Clear separation of concerns
- ✅ Easy maintenance and extension
